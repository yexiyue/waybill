## Bill 的身份特征

- 长而弯曲的鹅颈，米白与暖灰羽毛，深色翼尖。
- 橙色的喙和蹼脚，专注但友善的表情。
- **腿上的青绿色运单筒是识别特征**，全身版本应保留。
- 插画采用纸张与羽毛的轻微纹理；小尺寸头像使用简化轮廓。

头像采用头颈特写，全身图展示完整邮差身份。保持 Bill 的物种、颜色和运单筒
一致，后续表情或动作变体用现有资产作参考。

## 名称与文案

品牌名使用小写 **waybill**；中文名称为 **运单**。代码标识以实际 crate / API 为准。

| 场景 | 文案 |
|---|---|
| 英文品牌短句 | Resumable delivery. Both ways. |
| 中文品牌短句 | 可恢复交付，往返皆可。 |
| 吉祥物名 | Bill / 雁哥 |

品牌短句描述设计方向。M0 阶段的项目介绍同时标明「契约设计中」，避免把计划能力
表述为已经发布的实现。

字标与标题留出充分空间，装饰线限于少量路径或纸张线条，保证技术内容优先可读。

## 使用方式

- README 头图保持原始比例，通过布局宽度控制显示尺寸。
- 透明吉祥物可放在浅色或深色背景上，周围保留至少半个头宽的留白。
- 头像优先使用专用 mark，避免把全身图缩到无法识别运单筒和面部。
- 社交卡保持文字与人物完整，需要新比例时在重新生成时调整构图。
- 图片配备文字替代描述；重要技术信息继续使用 Markdown 文本表达。
- 后续变体使用 v2 等新文件名，并记录参考资产及提示词。

## 边界

这些是 PNG 品牌插画与标记，不是可编辑的 SVG 母版。若以后需要单色印刷、刺绣
或小尺寸矢量标记，可以在这一视觉身份基础上单独制作相应资产。

使用品牌资产时保持项目归属清晰，不暗示不存在的合作、认证或服务端兼容性。

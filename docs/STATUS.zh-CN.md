项目处于 **0.x 开发阶段，尚未发布稳定版本**。本地与 Google Drive、WebDAV、OpenDAL 对象存储之间的上传、

公开 API 仍可能调整；当前直接注入 service 端口，核心不提供自己的 Operator / registry；对象存储接受 OpenDAL Operator。

- 真实 Drive 与 PTY 验证盘配置、默认根目录、短路径、完整 URI、上传与下载多选、

## 架构审查与 API 重构（2026-10-02）

- 统一为 `TransferEngine::new(store)`，提供 `upload / download / confirm`；
  默认选项只需操作 ID 与目标引用，存储和预算不必每次重复传入。
- 回执、冲突策略和暂停归 `transfer`，摘要与验证归 `content`；上传与下载
  保留各自的生命周期契约。核心不解释目标的原生路径或后端引用语法。
- 端口显式声明读写块上限与上传对齐，引擎选择有效交集；身份、账本和回执
  的校验边界明确，已完成下载对账后再次复核远端版本。
- 移除未发布 v1 平铺 checkpoint 的兼容加载。旧记录保留并报错；实际本机
  有 13 条 v1 记录，因此 `status` 显示有效 v2 记录后返回非零诊断。
- GDrive 上传只声明长度验证；客户端 BLAKE3 属性继续绑定恢复身份，不能
  作为服务端内容校验结果。下载按实际摘要校验声明证据。

本轮 macOS 验证通过 123 项常规测试与 1 项文档编译测试，3 个子进程辅助入口
由父测试执行；fmt、all-targets check、全特性 Clippy 和 rustdoc 检查通过。
真实 Drive 17 MiB 文件完成暂停续传、重复上传、下载校验及重复下载，上传
重试保留同一对象，下载与源字节一致。Linux / 远端 CI 未在本轮运行。
详细环境、兼容影响和证据见[验收记录](VALIDATION.zh-CN.md)。

## 连续 TUI 会话与 status 面板（2026-10-02）

- `status` 在终端默认显示只读运单列表，支持详情、手动刷新与读取问题逐条查看。
  非终端、`--no-tui` 和 JSON 保持已有输出与退出码。
- 命令统一拥有全屏终端，选择器与传输面板借用同一会话；目录导航和步骤
  切换不再关闭再开启全屏。直接使用 ratatui / crossterm 的渲染和异步输入。
- macOS 验证通过 126 项常规测试与 1 项文档编译测试、fmt、all-targets check、
  全特性 Clippy 和 rustdoc；6 个 PTY 场景均只有一次全屏进入 / 退出，且终端恢复。
- 真实 Drive 验证上传选择 → 传输、云端选择 → 下载、本地目录 → 云端选择 → 下载，
  17 MiB 下载 SHA-256 与源一致；强制停止返回 130，旧记录诊断仍返回非零。

## WebDAV 接入（2026-10-02）

- 目录和文件选择统一使用开放的 `Service::resolve / list` 与 `ObjectMetadata`；
  后端构造留在 CLI 宿主，浏览器与队列不依赖 GDrive 类型。
- 增加 `StreamUploadSink` / `upload_stream`，复用预算、身份绑定和回执校验。
  普通 PUT 中断需要显式 `--allow-restart`，已验证暂存只重试发布。
- Apache 2.4.65 与 WsgiDAV 4.3.5 的 Basic / Digest 本地 Docker 矩阵通过；覆盖
  双向传输、空文件、字面文件名、冲突、根目录及真实请求中断后的整文件重传。
- 故障替身覆盖写入和发布已生效但响应失败，以及操作标记和版本保护。
  更多产品、反向代理和真实网络环境不在本次验收范围。

复现配置和服务端差异见 [WebDAV 验收记录](webdav-acceptance.zh-CN.md)。

## 对象存储接入（2026-10-02）

- 接入 OpenDAL 0.59.3，统一对象存储宿主配置和 `object://账户/key` URI；
  后端列表与实际 capability 分别检查，未支持操作明确报错。
- 条件范围下载、临时对象上传、读回 BLAKE3 校验、条件发布和完成回执已实现。
  writer 会话不进入 checkpoint，中断后需 `--allow-restart`；暂存完成后可只重试发布。
- 本地 RustFS Docker 覆盖 17 MiB multipart、128 MiB SIGKILL 后显式重传、内容校验、
  回执复用、冲突、操作后缀、根目录、Unicode 与空文件。真实 OSS 同一组场景及竞争发布保护已通过；COS 尚未验收。
- 架构审查后集中操作标记与 writer 生命周期；归属及内容检查绑定同一版本，
  服务器 copy 必须固定非 null 源版本，否则使用条件读回与重上传。
- 基线 Rust 1.91；默认数据预算 32 MiB，包含适配器的分片缓冲和范围读取复制。

配置和复现见[对象存储接入](object-storage.zh-CN.md)。

## 当前状态

项目处于 **0.x 开发阶段，尚未发布稳定版本**。本地与 Google Drive 之间的上传、
下载和持久恢复已实现；CLI 提供登录、盘配置、目录浏览、多文件传输与交互选择。
公开 API 仍可能调整，Operator / registry 等长期设计草图不属于现有 API。

| 范围 | 已实现能力 |
|---|---|
| 核心 | 开放上传与下载契约、能力声明、版本化 checkpoint、完成回执与有界传输调度 |
| 本地 service | 稳定源、范围读取、文件 checkpoint、下载暂存与校验、同文件系统无覆盖发布 |
| GDrive service | 分块上传、偏移续传、会话与完成对象对账、目录和对象访问、范围读取下载 |
| `wb` CLI | login / drive / list / put / get / status，命名盘与默认根目录，短路径、跨目录多选、全屏面板与 JSON 事件 |
| 独立消费者 | 通过公开接口接入上传与只读 service 的示例 |

## 验证范围

上传与下载均已完成本地分层测试和真实 Google Drive 验收。恢复验证涵盖进程中断、
源版本变化、完成结果丢失以及本地发布失败等窗口；具体场景分别使用本地替身、
契约测试或真实后端，不能把一种环境的结果当成另一种环境的验收。

最新 CLI 验收在 macOS / arm64 上完成：

- workspace 格式检查、all-targets check、Clippy、测试与 rustdoc 检查通过。
- 普通测试 115 项；子进程辅助入口由父测试实际执行。
- 真实 Drive 与 PTY 验证盘配置、默认根目录、短路径、完整 URI、上传与下载多选、
  跨目录保留选择、缺参交互补全、取消退出和终端恢复。
- 非终端与 JSON 模式缺参拒绝、配置边界与选择资源上限已验证。

本地 service 支持 Linux / macOS；最新一轮修改尚未执行 Linux 或远端 CI。
Windows 与浏览器没有支持承诺。真实限流、磁盘满、断电、长时间运行和更多网络
环境仍需补充；不支持跨文件系统复制发布。

详细结果、历史验收及环境限制以[验收记录](VALIDATION.zh-CN.md)为准。

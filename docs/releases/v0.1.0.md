## waybill 0.1.0

首个 crates.io 原型版本，提供 Rust 文件交付契约、持久 checkpoint、完成回执和 `wb` CLI。
公开 API 尚未稳定，支持 Linux / macOS；浏览器与 Windows 尚未验收。

- 核心：上传、下载、停止信号、冲突策略和有界共享资源调度，service 使用开放端口接入。
- 本地：稳定文件源、持久 checkpoint、下载区间账本与同文件系统无覆盖发布。
- Google Drive：分块上传、偏移恢复、远端对账、条件范围下载和目录访问。
- WebDAV：Basic / Digest / 匿名访问、流式上传、内容校验与条件 MOVE 发布。
- 对象存储：OpenDAL 的 S3、OSS、COS 等 11 种后端，按实际能力开放浏览、条件下载与上传。
- CLI：login / drive / list / put / get / status、交互多选、全屏面板及 JSON 输出。

Google Drive、两套本地 WebDAV 服务器、RustFS / S3 与真实阿里云 OSS 已在记录的范围内验收。
COS 等其余公有云尚未验收。WebDAV 普通 PUT 与 OpenDAL writer 中断需显式允许整文件重传，
不承诺跨进程 multipart 分片续传；ETag 不视作通用内容哈希。

发布 crate：`waybill`、`waybill-service-fs`、`waybill-service-gdrive`、
`waybill-service-webdav`、`waybill-service-opendal`、`waybill-cli`（可执行文件 `wb`）。

详细验证范围见 [验收记录](https://github.com/yexiyue/waybill/blob/v0.1.0/docs/VALIDATION.zh-CN.md)。
